# Overview

Welcome to the official documentation repository for **SurveySentinel**.

This repository contains publicly available product documentation, user guidance and reference material for the SurveySentinel software platform.

SurveySentinel is an intelligent aerial survey platform designed to enhance professional drone operations by helping operators capture more complete, consistent and reliable survey datasets.

The documentation in this repository focuses on **using** SurveySentinel rather than describing its internal implementation.

---

This repository exists to provide:

- Supported hardware information
- Release notes

Internal engineering documentation, software architecture and development resources are maintained separately.

# About SurveySentinel

SurveySentinel is being developed as a professional software platform for the DJI Enterprise ecosystem.

The platform assists survey professionals throughout the data capture process by providing intelligent workflow support and enhanced situational awareness during aerial survey operations.

The objective is simple:

> **Help survey professionals capture the highest quality data possible, first time.**

---

# Intended Applications

SurveySentinel is being designed to support a wide range of professional workflows, including:

- Building Surveys
- Roof Inspections
- Infrastructure Inspection
- Utilities
- Construction Monitoring
- Topographical Survey
- Asset Management
- Heritage Recording
- Digital Twin Capture
- Environmental Monitoring

# Supported Platform

Current development is focused on the DJI Enterprise ecosystem, including:

- DJI Matrice 4 Enterprise
- DJI Matrice 4 Thermal
- DJI RTK 3
- DJI Manifold 3
- DJI Enterprise Remote Controllers

Additional platforms may be supported in future releases.
